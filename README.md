# companion

This is the plugin that every Jurassic Ninja site is provided with.

It allows auto-login and a few other features specific to the [Jurassic Ninja](https://github.com/Automattic/jurassic.ninja) _system_.



## Rehearsal

**Tools → Rehearsal** runs repeatable, shareable step-by-step checks of the site in your browser, so
anyone verifying a change can repeat the same check the same way. See [rehearsal/README.md](rehearsal/README.md).
